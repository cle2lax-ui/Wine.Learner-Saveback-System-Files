# Arc 3 photo candidates (Mendocino)

**How each source verifies location.** *Commons:* the uploader's title and category, human-curated (the most reliable here).
*Unsplash:* photographer-set location on the photo record. *Pexels:* **none** (the API carries no location data); a place name
in a Pexels caption is the photographer's claim, so a Pexels photo goes only where the page does **not** state the location, or
after independent cross-checking.

**Licenses.** Every photo below is CC0, CC BY, Pexels or Unsplash: **none is share-alike**, so all are usable in the decks *and* the
summary Reel. CC BY requires attribution (the page credit, and the Reel's caption). Not downloaded yet: download at build time.
